Limitations

Whilst I tried very hard to make the experience of installing Linux as seamless as possible, there are limits to what is mathematically possible.
  • I cannot magically restore anything that has been deleted. Back up all files, documents, photos and music you care about, before installation. This type of software might hang, crash, or permanently damage your hardware. That does not mean it never works. It works perfectly fine for me.
  • Only two software distributions (distros) are currently supported: ZorinOS Core and Linux Mint Cinnamon Edition, and only specific versions. Other variants and other Ubuntu-based systems might or might not work, but you are on your own. If you know how to make your favourite distro work, send me an email.
  • These distros obviously have their respective minimum hardware requirements. Last time I checked, it was around ~20 GiB free disk (100 GiB recommended) and ~2 GiB RAM (6 GiB recommended). Check their documentation to be sure.
  • Because the new system needs to be installed on your disk from somewhere, the 'installation disk image' file needs to be either:
    • on a disk, but a different one, or in some safe place that will not be affected by the installation itself
    • in RAM (if you have roughly 6 GiB or more)
    • hot-downloaded on demand piece-by-piece ('paged in') from the network
    Networks in general are unreliable, and wireless ones even more so. 'Network boot' is very experimental and any interrupted connection can lead to a broken installation.
  • 'Network boot' over Wi-Fi is very limited and only provided as a last resort. While it does work for full disk installation, the live demo system has no Internet access (DNS). Workaround: if you must have Internet and absolutely must use wireless network boot, you can open a terminal and type sudo dhcpcd wlp1s0 (wlp1s0 may be different on your computer, try typing ip link first to see what your interface name is). If you have ideas how to fix it, send me an email.

Q&A

Q: How to install Linux without USB?

A: USB installation used to be recommended, but not anymore. The easiest way currently is to use a dedicated USB-less Linux installer like 1-Click Linux.

Q: Who is 1-Click Linux for?

A: 1-Click Linux is for Windows users who want to install Linux, but don't have external storage and don't want to buy a USB.

Q: Why should I use it?

A: Windows is getting worse and worse, but quitting is difficult. 1-Click Linux makes it as simple as it can probably get.

Q: Can I keep Windows?

A: Yes, it's called dual boot and the recommended distros support it. If you are not sure whether to keep it, keep it.

Q: Is this a WUBI reboot? LICK reboot? Is this ULLI?

A: Yes, and it goes even further: the system actually installs on a disk partition.

Q: I love this! Where can I get this?

A: You can buy it here.
