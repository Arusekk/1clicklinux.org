Einschränkungen

Während ich mich sehr bemüht habe, die Erfahrung der Installation von Linux zu vereinfachen, setzt die Realität manchmal Grenzen.
  • Ich kann nicht auf magische Weise wiederherstellen, was gelöscht wurde. Alle Dateien, Dokumente, Fotos und Musik, die Ihnen wichtig sind, sichern, vor der Installation. Diese Art von Software kann Ihre Hardware hängen, abstürzen oder dauerhaft beschädigen. Das heißt nicht, dass es nie funktioniert. Es funktioniert ganz perfekt für mich.
  • Derzeit werden nur zwei Software-Distributionen (Distros) unterstützt: ZorinOS Core und Linux Mint Cinnamon Edition, und nur bestimmte Versionen. Andere Varianten und andere Ubuntu-basierte Systeme funktionieren oder auch nicht, Aber Sie sind auf Ihnen allein gestellt. Wenn Sie wissen, wie Ihre Lieblingsdistro laufen zu machen, senden Sie mir eine E-Mail.
  • Diese Distros haben offensichtlich ihre jeweiligen Mindestanforderungen an die Hardware. Als ich das letzte Mal nachgesehen habe, war es etwa ~20 GiB freier Festplattenspeicher (100 GiB empfohlen) und ~2 GiB RAM (6 GiB empfohlen). Überprüfen Sie ihre Dokumentation, um sicher zu sein.
  • Da das neue System von irgendwoher auf Ihrer Festplatte installiert werden muss, Die 'Installations-Disk-Image'-Datei muss entweder:
    • auf einer Festplatte, aber eine andere, oder an einem sicheren Ort, der von der Installation selbst nicht betroffen sein wird
    • in RAM (wenn Sie ungefähr 6 GiB oder mehr davon haben)
    • heiß-heruntergeladen Stück für Stück auf Anfrage ('paged') aus dem Netzwerk
    Netzwerke sind im Allgemeinen unzuverlässig, und drahtlose Netzwerke noch mehr. 'Network Boot' ist sehr experimentell und jede unterbrochene Verbindung kann zu einer defekten Installation führen.
  • 'Network Boot' über Wi-Fi ist sehr begrenzt und nur als letztes Mittel zur Verfügung gestellt. Während es für die vollständige Festplatteninstallation funktioniert, hat das Live-Demosystem keinen Internetzugang (DNS). Problemumgehung: wenn Sie über Internet verfügen müssen und unbedingt den drahtlosen Netzwerkstart verwenden müssen, Sie können ein Terminal öffnen und sudo dhcpcd wlp1s0 eingeben (wlp1s0 kann auf Ihrem Computer unterschiedlich sein, versuchen Sie zuerst, ip link einzugeben, um zu sehen, wie Ihr Schnittstellename ist). Wenn Sie Ideen haben, wie es zu beheben, senden Sie mir eine E-Mail.

Übungen

F: Wie installiere ich Linux ohne den USB-Stick?

A: Früher wurde die USB-Installation empfohlen, aber nicht mehr. Der einfachste Weg ist derzeit, ein dediziertes USB-loses Linux-Installationsprogramm wie 1-Click Linux zu verwenden.

F: Wer ist 1-Click Linux für?

A: 1-Click Linux ist für Windows-Benutzer, die Linux installieren möchten, aber haben keinen externen Speicher und möchten keinen USB-Stick kaufen.

F: Warum sollte ich es benutzen?

A: Windows wird immer schlechter, aber verlassen ist schwierig. 1-Click Linux macht es so einfach, wie es wahrscheinlich werden kann.

F: Kann ich Windows behalten?

A: Ja, das ist genannt Dual-Boot (ein Computer hat beider Systeme, und man wählt am Start). Die empfohlenen Distros haben das. Wenn Sie nicht wissen, ob Windows loszuwerden, werden Sie es noch nicht los.

F: Ist das wie neuer WUBI? Neues LICK? Ist das ULLI?

A: Doch, und weiter: der System wirklich installiert auf die Festplatte.

F: Wunderbar! Wo kann ich das bekommen?

A: Gehen Sie hier.

F: Wann kommt der offizielle Version?

A: Einschreiben Sie Ihnen für den Newsletter. Ich überhäufe niemals — jederzeit abmelden.

F: Warum bezahlen? Ist Linux nicht kostenlos?

A: Weil ich hart gearbeitet habe, dieser Installer zu machen und ich habe bezahlt für diese Website. Sie können immer lernen, wie Linux zu installieren. Inbesondere wenn Sie Windows benutzen, das hat >100 € gekostet3, eigentlich können Sie mir ein bischen zahlen. Ich will auch essen.

F: Wenn ich muss zahlen, kann ich etwas zurückbekommen dafür, es mit allen zu teilen?

A: DOCH! Nach dem Kauf bekommen Sie eine Empfehlungskennung — andere werden einen Rabatt bekommen und Sie werden verdienen.4

F: Kann ich (oder jemand) den Quellcode überprüfen? Was ist die Lizenz?

A: Ja, egal wie kaufmännisch, dies ist Libre Software. Sie bekommen die Quelle mit den Binärdateien, und Sie können damit experimentieren, wie Sie wollen, sofern es sich an die GPLv3 hält. Das bedeutet, dass Sie auch Ihre Änderungen an mich verkaufen können!

F: Wie dieser Programm schutzt meine Daten?

A: Es stellt nur Netzwerkverbindungen her, wenn es explizit danach gefragt wird, und sammelt niemals irgendwelche Daten. Alles kann man deinstallieren jederzeit, indem man der Programm laufen lässt und diese Option wählt.

F: Welche Distros werden unterstützt?

A: Zurzeit nur zwei, Zorin Core und Linux Mint Cinnamon Edition, und nur die neuesten Versionen zum Zeitpunkt der Veröffentlichung. Verbesserungsvorschläge willkommen! Jede Ubuntu-basierte Distribution kann relativ einfach hinzugefügt werden (seiner Installer Casper mitmacht ganz gut). Aber ich werde etwas Allgemeineres für andere Distributionen finden müssen.
