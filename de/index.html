Übungen

P: Wer ist das für?

O: 1-Click Linux ist für benutzer, die hat Probleme mit Windows, die kann kein technisches Hilfe finded, und sind bereit für radikale Lösungen.

P: Warum das nutzen?

O: Windows wird immer schlechter. 1-Click Linux ist die einfachsten Ausgang.

P: Kann ich Windows speichern?

O: Ja, das ist genannt Dual-Boot (ein Computer hat beider Systeme, und man wählt am Start). Zorin OS hat das. Wenn Sie kennen nicht, ob Windows loszuwerden, werden Sie noch nicht los.

P: Ist das wie neuer WUBI? Neues LICK? Ist das ULLI?

O: Doch, und weiter: der System wirklich installiert auf die Festplatte.

P: Wunderbar! Wo kann ich das bekommen?

O: Zurzeit ist das alpha Software, so es ist besser nich es zu kaufen. Es war keinen umfangreichen Tests unterzogen, so es kann abstürzen oder ständig Ihrem Hardware schaden. Und es ist leider kein Übertreibung. Diese Sorte von Software führen gewöhnlich zu SCHWERE PROBLEME, einschließlich Computer wertlos machen.
Natürlich bedeutet es nicht, dass es niemand funktioniert! Für uns funktioniert es ganz perfekt.

P: Ich will es trotzdem kaufen.

O: Sie sind gewarnt! Gehen Sie hier.

P: Wann kommt der offizielle Version?

O: Einschreiben Sie Ihnen für den Newsletter. Ich überhäufe niemals — jederzeit abmelden.

P: Warum bezahlen? Ist Linux nicht kostenlos?

O: Weil ich hart gearbeitet habe, dieser Installer umzumachen und ich habe bezahlt für diese Website. Sie können immer lernen, wie Linux zu installieren. Inbesondere wenn Sie Windows benutzen, wie hat >100 € gekostet2, eigentlich können Sie mir ein bischen zahlen. Ich will auch essen.

P: Wenn ich muss zahlen, kann ich etwas zurückbekommen für es allen mitteilen?

O: DOCH! Nach dem Kauf bekommen Sie eine Empfehlungskennung — andere werden einen Rabatt bekommen und Sie werden verdienen.3

P: Kann ich (oder jemand) den Quellcode prüfen?

O: Ja, egal wie kaufmännisch, es ist freie Software, mit den Programm bekommen Sie die Quelle und Sie können experimentieren damit wie Sie es möchten, sofern es sich an die Lizenz hält.

P: Wie dieser Programm schutzt meine Daten?

O: Es macht keine Netzverbindungen, und sämmelt je überhaupt keine Daten. Alles kann man deinstallieren jederzeit, indem man der Programm laufen lässt und diese Option wählt.

P: Wie Distros werden unterstützt?

O: Zurzeit nur eins, Zorin Core, und nur eine Version. Schreiben Sie ruhig Verbesserungsvorschläge. Linux Mint ist der Nächste, und jeder Ubuntu-basierte Distro braucht den gleiche Ansatz (ihrer Installer Casper mitmacht ganz gut).

2026-03-20

The current prototype consists of two files: a self-contained executable file and an official disk image from the recommended distro (Zorin Core). Once you click on the executable, it prompts for disk access and asks several questions in order to configure a one-time reboot to live Linux, with the option to install permanently.

The only piece left before starting the public beta is figuring out some per-download payments.
